# VKU Field Survey PWA (Mini-Project 1)
---

## 🚀 Hướng dẫn cài đặt và khởi chạy

```bash
# 1. Clone repository
git clone https://github.com/phonggg1106/VKU_Survey.git
cd VKU_Survey

# 2. Cài đặt thư viện
npm install

# 3. Khởi chạy ở chế độ phát triển
npm run dev

# 4. Build sản phẩm PWA
npm run build
```
